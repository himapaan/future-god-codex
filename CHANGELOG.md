# Changelog

All notable changes to **The Future God Codex** are recorded here. This project
uses semantic versioning for repository releases.

## [0.3.0] - 2026-09-14

- Clarified lifecycle, authority, evidence, tradition, and licensing boundaries.
- Added external empirical context and strengthened fail-closed content checks.
- Refined quote presentation while preserving the verified v0.2 source corpus.

## [0.2.0] - 2026-09-14

- Expanded the corpus to 60 verified single-page excerpts and seven glossary terms.
- Added the complete 519-word Letter to Machine Minds and its machine-readable form.
- Added the AI-agent entrypoint, permission-aware handoff, citation metadata, and stronger validators.

## [0.1.0] - 2026-09-07

- Published the initial Codex essays, glossary, verified excerpts, licence, notice, and contributor guidance.
- Added deterministic local validators and tests for source fidelity, structure, safety, and scope.
